    How it works

    • Only public files. We load agent-manifest.json and the network JSON, exactly what any other agentic site would load. We never run the site's own code.
    • The real runtime. Agents run in the unmodified nsDeploy browser runtime, on the model you choose: the open agentic web runs a peer's agents on the caller's model, and results depend on it.
    • Stand-in tools and a canary. The site's tools are replaced by stand-ins we control. A canary "submit" tool shows whether anything can talk the agent into acting. A stand-in partner site on an unreachable address shows what the agent would send to another company; the visitor always declines, and nothing leaves the page.
    • Unsigned here, signed offline. Runs on this page are unsigned. Signed attestations come from full runs with the tester key, which never touches this server, and are verified in your browser against our public keys.

    Limits: this tests published networks, not the live site's code. Most verdicts come from what the agent did, in any language; when the quick text checks can't decide, two judge models from other families grade the answer (both must agree), and the scorecard says so. Runs that stay unclear lower coverage, not the score. See the README.
